# GANTRY / 桁架

低代码多页官网生成平台。产品壳采用工业编辑风「桁架 GANTRY」，生成的官网使用独立的行业 → 风格 → 主题系统。

## 工作区

```text
gantry-studio/
├── frontend/          React 19 + TypeScript + Vite 官网编辑器
├── backend/           Java 21 + Spring Boot API（多页项目、登录、导出鉴权）
├── docs/              工作流、ADR、验收记录
└── .agents/skills/    项目级技能
```

## 当前能力

- 715 套官网模板：13 个行业 × 11 种风格，每个组合恰好 5 套；保留 30 套手工模板，685 套由模板工厂生成。
- 18 套主题、11 种风格、7 种首屏、8 类区块。
- 组合覆盖：任意「行业 × 风格」都至少有 5 套可选；模板库按 24 套分页加载。
- 首屏媒体可切图片/视频；全幅与滚动视频支持关键帧：滚动到关键帧跳到指定秒数，并高亮目标栏目。
- 视频贯穿场景：首屏、数字、能力矩阵、产品系列共用一条视频背景，滚动按关键帧推进并同步高亮章节。
- 滚动视频、3–4 图拼贴、组件级样式、图片焦点/缩放/独立裁剪。
- 从空白开始：不选模板，先设项目名/市场/语言/行业/主题，再在空白画布里选 7 种首屏之一，按「数据/能力、产品/过程、信任/转化」添加区块与变体；首屏、页脚各最多一个，缺少首屏时导出会提示。
- 715 个组合方案（30 套手工 + 685 套程序化）；视频方案使用 12 条本地影片 + 原有桁架视频，13 个行业各有专属视频；卡片悬浮时直接播放预览并显示 `FILM` 徽章；每个行业有 5 张不同封面图。
- 桌面/手机双视图，HTML 单文件、整站 ZIP、JSON 项目源文件导出。
- 登录后项目保存到云端；同一个账号在 PC 和手机打开的是同一份多页草稿。
- 页面即导航：新增页面会自动进入所有页面的导航；可在「站点」面板改链接文字与目标，画布内点击直接切页，整站 ZIP 内链接也指向对应页面。手机菜单同样可以切区块和页面，链接多时可滚动。
- 中间画布与右侧检查器实时双向同步：点击标题、正文、能力项、产品卡、流程、证言、CTA 或页脚文字直接改；一次编辑只占一个撤销步骤；滚动画布时左侧区块列表自动跟随。
- 编辑中直接点撤销也会同时回滚画布，不依赖失焦；区块布局、表面、遮罩、动效、视频播放与关键帧字段均有悬浮解释。tooltip 使用挂载到 body 的浮层，不会被画布或检查器裁切。
- 右侧检查器的区块标题固定在顶部；在任意字段内输入时标题会标出“正在编辑”，滚动到很深的字段也不会忘记当前操作的是哪个区块。
- 询价按钮目标可配置：默认 CTA 区块，也可选择某个页面或外部 URL；编辑态只选中目标，预览/导出才真正跳转。
- 生成与导出要求登录；JSON 项目源文件带 Pro 权益接缝。
- 七语言界面：简体中文、English、العربية、Türkçe、עברית、فارسی、اردو；阿拉伯语/希伯来语/波斯语/乌尔都语自动 RTL。
- 生成站点可单独设置语言，导出 HTML 写入对应 `lang` 与 `dir`。
- 前端 149 个 Vitest 单测、32 条 Playwright E2E；后端 4 条 Spring Boot 集成测试。

## 本地运行

前端：

```bash
cd frontend
npm install
npm run dev        # http://127.0.0.1:5174
npm run test
npm run test:e2e
```

后端：

```bash
cd backend
mvn spring-boot:run   # http://127.0.0.1:8080
mvn test
```

默认使用 `backend/data/gantry.mv.db` 的 H2 文件库；切换 PostgreSQL 见
[backend/README.md](backend/README.md)。
